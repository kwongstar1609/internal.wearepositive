# BNI Positive LT System

Internal Leadership Team Operations System for BNI Positive Chapter (wearepositive.hk).

## Deploy to Vercel

1. Push this folder to your GitHub repository `internal.wearepositive`
2. In Vercel, import the repository
3. Deploy

This is a Phase 1 MVP covering dashboard, calendar, members, tasks, Traffic Lights calculator, presentations, seating, and activities.
